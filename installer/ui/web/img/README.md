Illustrations for the instruction screens. `<app>-<step>.svg` (or `.png`) replaces the
generic drawing next to that step, for instance `cleantv-preparer-la-tv.svg` or
`cleantv-samsung-se-connecter-a-la-tv.svg` (lowercase, no accents, dashes; portrait 4:5).
The current ones are drawn schematics of the TV menus, not screenshots. Rebuild the
installer to embed a new one.
