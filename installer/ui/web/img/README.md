Illustrations for the instruction screens. `<app>-<step>.svg` (or `.png`) replaces the
generic drawing next to that step, for instance `cleantv-preparer-la-tv.png` or
`cleantv-samsung-se-connecter-a-la-tv.svg` (lowercase, no accents, dashes). Clicking it
in the window shows it full size. Rebuild the installer to embed a new one.

The two `.png` stack real TV screenshots for a private installer: Fire TV ones from
justgeek.fr, Samsung ones from techdows.com (credited there to developer.samsung.com).
They are not ours to redistribute. The `.svg` are our own drawings.
