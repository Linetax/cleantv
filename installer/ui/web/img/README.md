Illustrations for the instruction screens. A PNG named `<app>-<step>.png` replaces the
drawing next to that step, for instance `cleantv-preparer-la-tv.png` or
`cleantv-samsung-activer-le-mode-developpeur-sur-la-tv.png` (lowercase, no accents,
dashes; portrait 4:5 looks best). Rebuild the installer to embed it.
